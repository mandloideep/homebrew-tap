# mandloideep/homebrew-tap

Homebrew formulas for tools by [mandloideep](https://github.com/mandloideep).
The formulas are generated by GoReleaser when a tool is released, so do not edit them by hand.

## Install

```
brew install mandloideep/tap/reclaim
```

That command taps this repository and installs the formula in one step.
To tap it first and install later:

```
brew tap mandloideep/tap
brew install reclaim
```

## Formulas

- [reclaim](https://github.com/mandloideep/reclaim): finds reclaimable disk space on developer machines and removes only what you select.
Shell completions for bash, zsh and fish are installed with it.
